# impossamole scripts

Working data lives in `M68000/scratchpad/impossamole/` (gitignored); scripts here are the ones worth re-running.
Run from `M68000/` with `ATARI_NOTRACE=1`; `resume ... repl` needs `--disk-a` every time. The REPL stops reading at
the first unknown line, so `.repl` files hold commands only (no `#` comments).

| script | start snapshot | what it does |
|---|---|---|
| `twintree_item_route.repl` | `scratchpad/impossamole/gameplay_explore/pass96_doublejump_v2.snap` | Walks left to the ledge foot, hops up+right onto the step, hops up+left at the item, sampling slot 0 (`$1a2ea`), the hero (`$1a572`) and health (`$bb74`) every 50,000 steps. Expected output: three sample triples, hero `(152,109)`, `(148,97)`, `(144,91)`, health `01`, slot 0 `type` `1`,`1`,`0`. Reproduced identically twice (98th pass). |
| `start_room_route.repl` | `scratchpad/impossamole/pass99/warp_up112.snap` | Plays the Amazon route's first two hops with real input: a labelled poke onto the block-151 exit into room `118..137`, then right walks, a ladder climb, a shaft hop and a fall through block 135 into `160..173`, then a second ladder, a zigzag of two shaft hops and a straight jump out through block 168 into `188..285`. Health is poked full at each segment start. Writes `scratchpad/impossamole/pass103/{room118,rock_top,box_edge,room160,room188}.snap`; expected final prints `00 bc 17 80 22 a0` then `00 60 00 90`. About 26.4M steps, `ATARI_NOTRACE=1`. Byte-identical to the interactively driven run (103rd pass). |

```
cd M68000 && ATARI_NOTRACE=1 dotnet exec bin/Debug/net8.0/M68000.dll resume \
  scratchpad/impossamole/gameplay_explore/pass96_doublejump_v2.snap repl \
  --disk-a "scratchpad/impossamole/impossamole cr replicants - emotion cr replicants.st" \
  < reversing/impossamole/py/twintree_item_route.repl
```

| script | what it does |
|---|---|
| `level_map.py <snap> <out.png> [--rooms] [--raw] [--x0 --x1 --scale]` | Renders the whole 1680x24 tile map (`$31800`) coloured by the `$25000` category; `--rooms` overlays room boundaries and exit triggers from `$c028`/`$e0aa`. Any snapshot in a world works: the map and tables are resident. Needs `uv run` (PIL). |
| `level_rooms.py <snap>` | Prints the current world's room graph (start room, every top/bottom exit with destination room and hero block-x). |
| `spawn_list.py <snap>` | Decodes the 256-record spawn list at `$27200` (column, y, type, allocator kind, descriptor, containing rooms). |
| `level_rooms.py <snap> --route S E` | Shortest exit sequence from the start room to a room containing blocks `S..E` (the boss room is `318 326`). |
| `boss_kill.py <snap> [pulses]` | Drives the boss fight with a live REPL: health poked full, real fire pulses, shot placed on the boss only while it is in its open animation. Needs `ATARI_NOTRACE=1`-style REPL access (it sets it) and the DLL in `bin/`. From `scratchpad/impossamole/pass99/boss_dead.snap` it took the boss from 16 hit points to 0 in about 20 pulses. |
| `tiles.py <snap> [--sheet out] [--level out --b0 --b1] [--cats out --b0 --b1] [--palettes out] [--check]` | Decodes the 256-tile bank (`$29800`), renders the level from block map `$27600` + block definitions `$29000`, tints the `$25000` collision categories over it, dumps the five world palettes (`$2166e`), and `--check` slides the rendered level over the live screen (expect about 98% at offset (32, 8)). See `graphics.md`. |
| `sprites.py <snap> [--bank 1 out] [--bank 2 out] [--font out] [--frame bank idx out] [--check]` | Renders sprite bank 1 (`$3b600`, 16x16) and bank 2 (`$42e00`, 32x24) contact sheets and the 8x8 font (`$24000`); `--check` blits each live object slot's frame at its declared position and counts pixels equal to the screen. |
| `spawn_types.py <snap> [--sheet out.png] [--check]` | Decodes the descriptor of every spawn type (kind, hit points, damage, handler, animation pointers) and draws its frames (`graphics/amazon_spawn_types.png`); `--check` joins each live kind-1 slot to its descriptor and to the pixel match of its frame at its declared position. Any Amazon snapshot works. |

## Subdirectories (104th pass)

Scripts written by the parallel pass; each subdirectory imports its own helpers and the modules above, and finds the repo root from its own
location (`M68000_ROOT` overrides). Their data and snapshots live in `scratchpad/impossamole/agents/<area>/` (`hop3`, `hop4`, `boss`, `spawn`,
`wsel`, `world12`, `world34`; indexed in `scratchpad/ANCHORS.md`), and the `.repl` files write their snapshots there. Run from `M68000/` with
`ATARI_NOTRACE=1` for anything that starts the emulator, `uv run python` for Python.

| directory | what |
|---|---|
| `route/` | the event-driven driver and the Amazon route on real input. `route_driver.py` is a live-REPL `Driver` (per tick read hero x/y/busy, `$227f3`, room and camera words, health, sensors; send a `kbd` packet only when the wanted bits change; log the state-changing commands to a replayable `.repl`; `hold`, `hop`, `land`, `poke_health`, `objects`, `snap`; refills health at 4 as a labelled poke). `route_hop3.py` = the 11 segments from `pass103/room188.snap` to room `299..318` (`uv run python .../route_hop3.py [seg ...]`, about 130 s). `verify_route.py` replays every segment and the whole route and `cmp`s the snapshots (expect `ALL IDENTICAL`, about 4 min). `hazard_census.py` replays the route with each step as `bp e82e n` (expect `99 damaging contacts, final snapshot identical to the live one: True`, about 12 min). `route_report.py`, `ascii_map.py <snap> <col0> <col1>` (collision map by category). `route_full_real.repl` = the whole route on real input in one file: hop 3 then the room `299..318` segments (7397 commands, about 4 min) from `pass103/room188.snap`, writing `agents/hop4/boss_room_real.snap` and `boss_room_real_settled.snap`. |
| `shop/` | room `299..318` to the boss room and the shop. `route_driver.py` (a second driver, the one hop 4 was built on: `--real` runs the five segments plus the settle from `agents/hop3/room299.snap`, `--shop` the shop branch `seg5b`-`seg11b`, `--control` the early-down control; the two drivers should be merged), `stage_room299.repl` (labelled poke into room 299 from `room188.snap`), `exit_proof.repl`, `real_exit_proof.repl` (`bp 18ed4`: D0 `$13e`, D7 1), `replay_check.sh`, `real_replay_check.sh` (nine "byte-identical" lines), the shop segments, `grid.py <snap> <b0> <b1>` (text collision grid), `shop_frames.py`, `shop_shots.py`. |
| `boss/` | the boss fight on real input. `boss_fight.py [--weapon N] [--poke-health] [--delay N] [--chain] --out name` (from `pass99/boss_room.snap`; natural kill `--weapon 3 --delay 180000 --chain`, expect `RESULT hp=0 $22803=ff ... hits=20 pulses=25`), `swipe_check.py` (expect `match 108/108`), `aim_trials.py` (`ground_low`, `straight_low`, `ground_plat` 0 hits, `hop_plat` about 8), `contact_check.py` (`health 18->17 ... boss 104=1 shots=[]`), `repl.py` (REPL wrapper that also captures `watch` output on stderr). |
| `level_end/` | the level-complete path. `win_amazon.repl` (resume `pass99/boss_kill_end.snap`: `$fbcc` 2905652, `$f0ee` 46, `$b0b2` 3985684, `$b0ca` 8244047, `$17c9c` 8244050, `$17df4` 148, `$183c0` 0), `win_amazon_last_of_four.repl` (poke `w bb78 001b0000`: Bermuda unlocks), `w5_ending.repl` (poke `w bb74 12120500`, world 5: `$183c0` at 8244117) and `w5_exit.repl`, `go1/go2/go3_death_mask.repl` (Game Over and title path), `w22800/w66/wscore.repl` (watches), `load_orient/iceland/bermuda.repl` (real-input world loads), `state_dump.py`, `boss_writers.py`, `spawn_kind2.py` (spawn list that tolerates non-mid-level snapshots), `dump_text.py`. |
| `worlds/` | the other four worlds. Cold-boot scripts `klondike_boot.repl`, `orient_boot.repl`, `ice_script.txt`, `bermuda_full_script.txt` (`ATARI_NOTRACE=1 dotnet exec bin/Debug/net8.0/M68000.dll 800000 repl --disk-a <disk> < script`); `world_pipeline.py <gameplay.snap> <name>` and `render_world.py <snap> <prefix> <outdir>` (all static assets of a world, categories 5-8 tinted); `compare_banks.py <ref> <other>...`; `census_warps.py <snap> <name> --jobs 5` (poke-warp into every exit record: 23 MATCH Klondike, 30 Orient), `census_walk.sh`, `type_census.py`, `warp_room.py <in> <out> <block> <0\|1>`, `end_level_poke.py`, `boss_kill_world.py` (keeps `$bb76`, knows the Bermuda shield), `slide_test.py`, `walk_test.py`, `conveyor_test.py`. |
| `spawn/` | spawn-type behaviour proofs (`run_all.sh` runs them all, about 5-10 min, output under `agents/spawn/out/`). `replx.py` (live REPL driver), `trace_frames.py` and `timeline.py` (frame-synchronised at `$b4de`), `live_census.py` (which types are live in which of 148 snapshots), `anim_map.py` (every animation list `$21f00..$22300` with its control word), `spawn_behaviour.py`, `flier_paths.py` + `verify_fliers.py` (expect `418/418, 92/92, 36/36, 418/418, 418/418, 418/418`), `immune_shot.py` (hp >= 128 immune: 8 rows with `$13b14 x1, $13b20 x0`), `marker_shot.py` (type-251 containers), `trigger_scan.py` (`12/12`, `17/17`, `7/7`), `chase_check.py`, `wander_check.py`, `monkey_trigger.py`, `monkey_drop.py`, `rock_hit.py`, `slab_crush.py`, `croc_ride.py`, `walker_swap.py`, `bush_swap.py`. Each script's docstring labels its pokes. |
