Inside Lemmings

Every skill in the game is a bit in one 32-bit word, and every collision is one of two lookups: a one-bit terrain bitmap or a map of 4-pixel cells. We booted the original disk in an emulator, handed lemming 0 each skill, and watched what the memory did.

The record

One lemming is 44 bytes

The array starts at $23484. Each tick a loop at $7802 loads x, y and the state word, tests the bits in a fixed order, and jumps to that bit's handler. A word of zero means walk.

Two ways to collide

The ground is a bitmap, everything else is a cell

Walking, falling, digging and bashing all test or edit the terrain bitmap. Walls for turning, exits, traps and steel live in a separate map, checked after every move.

Terrain bitmap

One bit per pixel, plane 0 of the level image at $41806, row stride $330. Set means solid. The walker reads the pixel it stands on, then looks down and up from there.

Object map

One byte per 4 by 4 pixels, $62f80, stride $198. After every update, $8b6e reads the cell under the lemming and acts on its low nibble; the high nibble names the level object that stamped the cell.

Steps and objects

How high is a step, and what the cells do

Flat ground, a solid step of 0 to 8 rows put in front of lemming 0, one sample per tick. Then the same lemming set down on level 1's own exit, with the exit cells swapped for each other code.

Step sweep

The step is poked into the bitmap at x = 752 (an input). Dots are the lemming's y on each tick it moved; orange ticks have bit 13 set.

Level 1's exit is two cells at column 222, rows 33 and 34 (world x 888, y 132 to 139). The lemming is placed at x = 870 on the ground beside it (a position poke); the pen it normally paces in ends at x = 853.

Each object keeps a 34-byte copy of its type at $23044: frame, frame count, size and trigger cells. A trap is a one-shot: the first lemming starts its 15 frames, one a tick, and a lemming arriving during them walks through (driven: the second lemming crossed at frame 9 and lived; one arriving 10 ticks after the end died).

The eight skills

What each one does to the world

Each plate replays a real run: the pixels are the game's own terrain bitmap, sampled from the emulator. Orange marks terrain the skill removed, gold marks terrain it added. Drag the slider or press play.

The state word

Seventeen bits, in priority order

When several bits are set, the one nearest the top of this list runs. A solid outline means we watched the bit set and its handler move the lemming; a dashed one is read from the code or unnamed.

How this was checked

Every plate comes from a snapshot of the game after level 1 starts. The skill index and count were set directly, then the pointer was aimed at lemming 0 and a click sent to the game's own handler. A control from the same snapshot, with no click or without the poked feature, is the comparison. Walls, pits and steel cells in the plates for climber, floater, basher and the steel tests were written into memory to give the skill something to meet; the level itself does not contain them.

The exit and trap runs place lemming 0 beside the exit by writing its x and y, and the step sweep writes the step into the bitmap. The trap runs also copy a trap's type record over the decoration above the exit. Still open: the object pictures, and the blocker's refusal test.
