# py/secrets: scripts behind `../../secrets.md`

Run from `M68000/`: `uv run python reversing/cadaver/py/secrets/<script>`. The scripts from `cad_lzh.py` down and `overlay/` come from two subagents (their outputs go to `scratchpad/cadaver/secrets_out/`). Every live script opens its own REPL through `repl.py` (`ATARI_NOTRACE=1`, the existing
`bin/Debug/net8.0/M68000.dll`, the Empire one-disk disk from `../Cadaver/`) and starts from `scratchpad/cadaver/gameplay_empire.snap` (CAVERN, day 1; regenerate per the
README's "How it was run" if missing). Keyboard input is a real make, a 40,000-60,000-step hold and a break (the game's ACIA handler keeps one cell and the main loop polls it).
