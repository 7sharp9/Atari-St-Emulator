## Known traps

- **A directory named `build/` is gitignored** (`.gitignore:52`): `py/build/` stayed untracked until renamed `py/worldbuild/` (in CLAUDE.md).
- **`callcap` presets are hex**: `D0=10` is `$10`. `$1699e` was called not callcapable from a listing that started two bytes early.
- **`hits` after a `bp` counts only from the stop** (new this pass, now in CLAUDE.md): the first Play Random Land run read `$13ece`, `$13b9a`, `$b85a`, `$b2dc` as 0 hits for exactly this reason; rerun `hits` from the end of the click, before any `bp`.
- **`gate_coverage.py` counts a cite, not an execution**: `$15c46` runs in the fsm15 gate through mode `$5a` and still lists as ungated.
- **`callcap` outcome `THREW ... WriteEa: immediate operand is not a valid destination`** is a runaway, not an emulator bug: four synthetic `fsm15` states throw it and are the "5 unrun".
- **A model gate caches callcap JSON**: a `reuse` run keeps stale deltas; delete the state's JSON or run without `reuse`.
- **`bpc <addr> <n> <max>` counts hits from the start snapshot, and `max` bounds the whole gap** (`capture_hits.py --max` defaults to 50M; pages-0 land captures needed `--max 30000000`, the preview roll `4000000`). A hit it does not reach still leaves a `.snap` with no `.ram`: filter on `.ram`. **`bpc` gives up after 200000 steps by default**.
- **Transcribe from the listing, not from a similar neighbour**; **a failure branch that always follows another failure is a clue**; **`add.w`/`subi.w` + `bge/blt` test N xor V**, so a wrapped word's sign is wrong.
- **macOS `seq -s,` leaves a trailing comma**; **the Edit tool drops trailing spaces from `new_string`**; **bucket links of records below `$51b66` are negative 16-bit offsets** (`_objaddr`); `snap_render.py` shows the shifter base at the snapshot (a `$f898` stop renders the iso view fine); `py/build_land.sh` needs `python3` on the Mac (fixed: falls back when `py` is absent).
- A subagent audit of docs finds real contradictions but also invents none: all three 142nd agents' claims that were spot-checked held (the minimap offset, the `$661a` relabel). Still spot check one per agent.
- Earlier traps still apply: a routine's tail that ends in the iterator's `bra $1622c` cannot be `callcap`ed in place; REPL `w` takes longwords at even addresses; entity records are the first 512 only; one entity tick is ~200k steps; `py/clicks.py` pointer moves 1:1; do not reopen the SingleStepTests track or `$4342`'s 8 proven branches; a full `pm_export.py` rerun regresses `entities.json`.
