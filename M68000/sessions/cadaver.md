## Known traps

- **Hold timing and phase** (unchanged): a hold starts moving ~40,000 steps after the press, then one cell per ~10,000 steps; a stall detector needs six 20,000-step chunks, an exact cell needs `goto` with 5,000-step chunks (a `drv.walk` with 20,000 stops before the hero moves: use 50,000); `Repl.__init__` runs `s 1`, so every route script snapshots, closes and reopens after each hold (a no-op hold still changes the phase and the route depends on it); after a room arrival wait ~100,000 steps; a continuous run diverged in room 19.
- **Waiting is a move:** room 15's patrol, room 38's spawns (creatures appear ~100,000 steps after arrival), room 36's fireballs (from ~100,000 steps) all depend on how long the hero stands still; a hold that "costs 30" may be an unlucky start time, so measure at several waits before calling a leg a hazard.
- **`from route_lib import *` used to overwrite the importer's `HERE`** (fixed this pass: `_HERE`); scripts copied into a scratch directory with `OUT`/`TK`/`SN` pointed there wrote snapshots into the repo's `overlay/action/snaps/` (three agents; the directory was deleted). A copy that sets `HERE` before the import is safe now; check `git status` for a stray `snaps/` before a commit.
- **After `H.real()` (an injected script) do not drive without a reload**: an R hold moved nothing in 400,000 steps in level 1 and in room 36 (a natural run moved it). Snapshot, close and reopen after any injection.
- A fire probe with nothing in front starts a jump; a probe snapshot can be mid-jump (`s 300000` lands it). A fire probe sees only the object directly ahead; items that are no obstacle (keys, pickaxe, gems, water 214) are pushed ahead by a walk or found by stopping beside them.
- Placement rectangles scroll with the hero's room-local coordinates only for the room's own origin: an object's y changed by 16 when the hero moved 20 cells (room 46); read a rectangle at the stall, not at the arrival.
- Injected-state results (health 100, items by verb 35, entries by verb 37) show a mechanism, not a route: label them so; a poked trap byte, a poked variable or a hand-poked cast (`2433(A5)`, `464/468/472(A5)`) can read a zero field the real handler would fill (the missile power read 0).
- Health: only verb 45 raises it (waters 213/214 +2, flasks 135 +2, 392 +10, potions, the level start); touch hazards cost per frame while overlapped (event 9); never hold a direction through an unknown rectangle; prune searches on health loss.
- Door words are hex door numbers; `$ffff` doors need their opener; a keyed door's flag byte decides consume, keep or permanent pass.
- The REPL prints at most 4096 lines; `watch` prints to stderr (`Repl.err`); a background command piped through `| tail` shows nothing until it exits; zsh does not word-split an unquoted variable; `w <addr> <8 hex>` writes four bytes (use `ww`/`wb` from `ov.py`).
- Earlier traps still standing: name an event from a live drive; a delete compacts the resource block, so object ids read after an action can be wrong; verb 66 with a class other than 10 kills the REPL; `cadaver.sym` labels are nearest-below; `tools/disassemble.py` takes bare hex arguments; verbs 8 and 75 assert unless the id is a creature, verb 29 needs A4 in valid RAM, verb 79 with lo = hi divides by zero; the placement table at `56(A5)` (stride `$46`) starts with the hero and a deleted object's rectangle is 255s; a queue entry is 8 bytes (12 with bit 15) and the write pointer `304(A5)` advances by 8.
